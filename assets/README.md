# README visual identity

The two SVG covers share an index-card illustration and the slogan “Choose the benchmark. Understand the evidence.” The design contains no benchmark scores, inventory counts, or claims of independent reproduction.

- `readme-hero-light.svg`: warm paper, forest-green type, and a lime bookmark.
- `readme-hero-dark.svg`: deep green, ivory type, and the same lime accent.

Both assets are self-contained SVGs with system-font fallbacks, accessible titles and descriptions, and a 1200 × 232 viewBox. Keep their geometry aligned and avoid scripts, external images, remote fonts, animation, and embedded links. The real catalog link belongs in the README text.

The READMEs use GitHub's [theme-aware picture element](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/quickstart-for-writing-on-github#adding-an-image-to-suit-your-visitors) with the light cover as a fallback. Keep the HTML image height automatic so the cover scales proportionally on narrow screens. The localized entry points are generated by `scripts/build_localized_readmes.py`; edit the generator rather than their output.
